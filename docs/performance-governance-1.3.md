- 本地起点为 `e49a5f8`，当前 manifest 为 `1.3.2-1`；前序静态服务、完整载荷、管理页请求治理及升级兼容改动保留在当前工作树。1.3.2-1 FPK 已生成，但尚未部署现场。
- 用户提供《QwenPaw（FPK）控制台性能排查报告》（2026-11-17）：报告针对早期 `1.2.7-7`，提出预压缩、缓存、轮询和资源卫生问题。其测量是调查输入，不自动作为 1.3 或现场 `-10` 的结果。
- 本轮只读核对现场 manifest 为 `1.2.7-10`，内核 `2.3.0`；基础 `CompressedStaticFiles` 与非入口静态文件 300 秒缓存已存在。现场清单 915 项，本地新增 `app/console_static.py` 后为 916 项；908 个 Console 载荷与现场一致。
- 现场额外声明 1683 项旧 Console 文件，每项附原始 SHA256。1.3 继承此显式清单，拒绝未知内容；不凭静态图推测删除，不触碰线上资源。
- 原有 908 项 Console 载荷为相对官方 wheel 的差异，不是完整目录。引用完整性须基于固定官方 Console 加差异减已知旧文件，或改为独立完整载荷；图标、字体与 worker 不能因未在差异清单中出现就判为线上丢失。
- 隔离 Python 3.12.4、FastAPI 0.163.1、Starlette 1.10.0、httpx 0.28.1 下，前序静态及路由回归 31 项通过。源码补丁可从固定上游提交 `0a21644e90d8ba37e20035b3bfb63880872cc2a2` 以 `--fuzz=0` 重建后端载荷。
- 10 个入口资源隔离 ASGI 重放：原文 3,062,440 字节，gzip 927,804 字节，Brotli 830,867 字节。现成压缩类与增强类传输量相同；这是约 73% 的静态字节减少，不是完整首屏或生产 CPU/可交互时间提升。

原始测量、临时源码、凭据和构建文件位于主项目之外。正式报告仅保存非敏感汇总、命令、被测版本/摘要及失败记录。

## 确定性门禁

- 清单路径、重复项、源文件集合、摘要和删除清单均有效；压缩兄弟文件解压后与原文一致。
- 静态内容哈希资源长期缓存，非哈希短缓存，入口 HTML 与 SPA 深链禁止缓存并正确注入 base-path。
- br/gzip/identity 编码偏好与禁用、MIME、Vary、HEAD、ETag/304、404 和路径边界一致。
- 有效 SSE 直接渲染已验证快照；断线、初次同步和 30 秒兜底仍可查询；旧回包不得覆盖新快照。
- 页面隐藏后停止周期刷新；同一任务最多一条在途请求；恢复触发合并，销毁后不补跑。
- 日志首次 2000 行、后续 100 行、15 秒周期与手动滚动保持；相同窗口不重建 DOM。
- 安装任务 `seq + instance`、授权回调、安全租约、停止与恢复边界保持，不统一降低轮询频率。

## 性能测量口径

管理控制台和上游 Console 分开测；上游直连、独立反代与 fnOS Gateway 分开记录。冷缓存、热缓存、后台、启动预热与稳定空闲必须标记，不能混成同一窗口。

记录请求数、原始/传输字节、编码/缓存、并发峰值、可交互时间 P50/P95、服务端进程 CPU、RSS、FD、线程和读取计数。ASGI 客户端与服务混合 CPU 只可作测试进程耗时，不能写成部署服务 CPU。

继承初始依赖图预算：raw 4 MiB、Brotli 1.2 MiB，单个初始 JS raw 2.5 MiB、Brotli 0.75 MiB。动态预加载 16 与全页资源并发分别记录。管理 API 在隔离就绪环境以 10 个只读客户端评估 P95 500ms、P99 1s；无基线或环境不满足时保留阻塞。

24 小时稳定性提供可运行入口；本轮短时运行不冒称 24 小时通过。

## 升级兼容与数据保留

用户明确要求旧版本可升级，必须保留本地文件与用户数据；venv 是可重建运行环境，不是必须原样保留的升级内容。重建必须沿用合法精确版本钉；除用户明确批准的 `1.3.3-1` 健康 2.3.0 → post1 事务迁移外，不隐式升级或降级内核，不重复初始化已有数据。

验收比较配置、记忆、认证、授权目录登记、用户工作区及应用 home/var 中非运行时文件的字节、类型与权限；旧环境保留、精确重建和失败回滚均适用。日志、Socket、PID、管理锁和事务记录按其生命周期单独核对，不混入“所有文件不变”结论。升级不递归重设用户目录权限；明确管理文件仍遵守 token、版本钉和事务文件的最小权限要求。

## 实施边界

保留 Rust 唯一管理核心、Preact 前端、Gateway-only、外壳/内核版本双轨与现有事务，不新增管理服务。QwenPaw `2.3.0` 载荷补丁仅对精确 pin 生效，未知源码修改必须拒绝覆盖。

上游 agent/ReMe/MCP watcher 先做归属与成本评估，不在本阶段直接降频。不修改模型、技能、认证、记忆和用户工作区；不自动安装、重启或替换测试机当前应用，不 commit、push 或发布。

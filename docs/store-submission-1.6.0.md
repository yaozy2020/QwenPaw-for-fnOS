### 简短介绍

QwenPaw for fnOS 是面向飞牛 NAS 的第三方部署外壳，提供 QwenPaw 内核安装、版本管理、状态监控、日志、目录授权和访问配置。

### 完整介绍

QwenPaw for fnOS 是由 yaozy2020 维护的第三方部署外壳，与 QwenPaw 上游团队无隶属关系或官方背书。

应用提供内核安装与版本管理、运行状态监控、日志筛选与导出、端口与独立 Web 反代配置、工作目录授权、下载源切换，以及安装前业务数据备份入口。管理台支持桌面与移动布局、自动/白天/暗夜主题和简体中文/English 界面。

QwenPaw 本体不随 FPK 分发。首次使用时，需在控制台选择内核版本，并联网从所选 PyPI 镜像下载内核及依赖；FPK 内置匹配版本的兼容补丁与预构建 Console，无需在 NAS 上现场构建源码。「随包适配补丁」仅表示版本与补丁匹配，不代表飞牛或上游认证，也不构成稳定性保证。

## 权限、网络与数据说明

- 应用以 fnOS 专用包用户运行，未声明 root 常驻运行。
- 声明 `trim.file.sharedAccess`、`trim.file.userAccess`、`trim.file.userAcl`、`trim.file.path` 四项文件能力，以及 `qwenpaw` 共享数据目录；工作目录由用户授权，解除绑定不删除文件。
- 管理控制台与主 Web 默认通过 fnOS Gateway 访问；内核仅监听本机回环地址。独立 Web 反代默认仅监听本机，用户显式开启后才允许局域网访问。HTTP 不加密，不应直接暴露到公网。
- 外壳安装内核时需要访问用户选择的 PyPI 镜像。QwenPaw 上游功能可能按用户配置访问模型服务、频道或其他外部服务；这些网络连接及相应数据处理由用户在上游 Console 中配置，不应宣传为完全离线或数据绝不出机。
- 保留数据卸载保留配置、聊天记忆与认证；彻底删除应用数据不可撤销。安装前 tar 备份只覆盖说明中列出的业务数据，不等于整机或全部应用数据备份。
- 上游 WebSocket 当前不由外壳代理，相关请求返回 501。

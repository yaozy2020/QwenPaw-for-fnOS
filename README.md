# QwenPaw for fnOS

[![Version](https://img.shields.io/badge/version-1.5.7-3-blue)](https://github.com/yaozy2020/QwenPaw-for-fnOS/releases)
[![License](https://img.shields.io/badge/license-Apache%202.0-green)](LICENSE)
[![fnOS](https://img.shields.io/badge/fnOS-%E2%89%A5%201.2.0800-orange)](https://www.fnnas.com/)

面向飞牛 NAS（fnOS）的 [QwenPaw](https://github.com/agentscope-ai/QwenPaw) 轻量部署外壳。外壳基于 Rust 负责内核安装、进程监管、配置事务与运维控制台；QwenPaw 本体由用户在控制台中从所选 PyPI 镜像按需安装，不打包进 FPK。

> 本项目是由 yaozy2020 维护的第三方打包项目，与 QwenPaw 上游团队无隶属关系或官方背书。

## 核心功能

- **服务与版本管理（概览）**：实时查看运行状态、CPU 使用率、内存占用、进程 PID 与运行时间；支持启停、重启、在线安装/升级/降级/重装及仅卸载内核。安装采用独立暂存环境与事务提交，失败时尝试恢复原运行环境。
- **配置与鉴权（配置）**：修改界面语言、外观模式与界面风格（默认 / Miuix），调整内核回环端口、独立 Web 反代端口与局域网访问范围；明确飞牛桌面入口与独立反代的登录方式，查看 Web 登录验证与管理员身份状态，支持将旧账号迁移到飞牛入口登录，以及在适配内核运行中通过飞牛管理员重置 QwenPaw 原生管理员密码（无需旧密码，不影响飞牛账号、配置与聊天记录）。
- **目录授权与备份（授权与备份）**：通过飞牛文件授权绑定、重新授权或移除工作区目录（移除绑定不删除文件），可按宿主能力打开目录，并直达 QwenPaw 上游备份管理页面及查看离线恢复说明。
- **日志阅读与诊断（日志）**：实时查看、自动滚底、按级别与关键字筛选、复制当前筛选结果、导出和清空运行日志；移动端采用阅读器层级，浅色与暗色主题均保持清晰对比度。
- **主题、风格、双语与多端适配**：管理台基于 Vue 3 + TypeScript 预编译为静态单页，NAS 端无需额外 Node 服务；支持**跟随系统 / 白天 / 夜晚**三态外观模式、**默认 / Miuix** 两种界面风格（含首屏防闪屏、状态栏色值与授权回调页同步）及**跟随系统 / 简体中文 / English**界面语言切换（含跨标签页同步与后端提示本地化）；桌面端采用侧边栏布局，移动端采用底部导航，切页或刷新后可恢复进行中的安装任务。

## 安装与首次使用

### 环境要求

- fnOS **1.2.0800 或更高版本**。
- `nodejs_v24`、`python312` 运行依赖由 fnOS 按应用声明自动处理。
- 如需接入 Ollama，请另行安装并配置 Ollama 服务。

### 安装步骤

1. 从 [Releases](https://github.com/yaozy2020/QwenPaw-for-fnOS/releases) 下载 `.fpk` 安装包。
2. 在飞牛应用中心选择「手动安装」并上传文件；手机端上传受限时，可先将 `.fpk` 放入 NAS 目录，再选择「从 NAS 添加」。
3. 按安装向导设置下载源、服务端口与日志级别。
4. 安装完成后打开「QwenPaw 控制台」，在 **概览 → 部署版本** 中点击「检查更新」获取版本列表：
   - 若下载源包含本包携带适配补丁的内核版本，控制台会标记「随包适配补丁」并预选（该标记仅表示补丁匹配，不代表官方认证或稳定性保证）。
   - 也可手动选择其他版本；未携带适配补丁的版本在确认安装前会提示飞牛桌面 Web 入口可能受影响。
   - 点击安装并等待下载依赖、安装内核与启动检查完成，之后即可点击「进入 Web 对话」。

> 内核与依赖需联网从所选 PyPI 镜像下载，耗时取决于网络状况、镜像响应和磁盘性能。安装使用 `uv` 并发解析依赖并复用持久缓存；请勿在外壳升级或已有任务运行时重复提交。任务在 NAS 后台执行，转到后台或关闭页面不会取消安装；弹窗阶段以任务状态为准，下方终端仅显示最近诊断输出。

## 访问方式与鉴权

| 入口 | 地址 / 位置 | 用途 |
|:--|:--|:--|
| QwenPaw 控制台 | fnOS Gateway `/app/qwenpaw/` | 内核安装、启停、配置、授权与日志 |
| QwenPaw 主 Web | fnOS Gateway `/app/qwenpaw/web/` | AI 对话与上游 Console |
| 独立 Web 反代 | 控制台「配置」显示的动态 TCP 端口 | 不经过 fnOS Gateway 的主 Web 访问 |

- **网关与隔离**：桌面图标和控制台「进入 Web 对话」均通过 fnOS Gateway 代理访问，不直接暴露内核端口。内核仅监听 `127.0.0.1`；独立 Web 反代仅转发主 Web，不挂载外壳管理 API，也不接受伪造的 fnOS 身份头。
- **独立反代端口**：与内核回环端口分开配置（输入 `0` 自动分配）。修改时会先尝试绑定新端口，成功后再切换，失败保留原端口；默认仅监听本机，可在「配置」中按需开启局域网访问。HTTP 明文不加密，请勿直接暴露到公网；公网访问请通过外部 HTTPS 反代转发至独立反代端口，并保留原始 `Host` 头（含非默认端口）。
- **账号、入口迁移与密码重置**：独立 Web 反代始终使用 QwenPaw 原生账号；飞牛桌面入口可在旧账号核验后迁移为飞牛管理员身份。内核回环端口只供外壳和反代内部连接，不作为第三种用户登录入口。旧反代密码文件和旧会话不再读取或接受；升级时旧密码文件保留但不参与认证，也不会自动删除。首次安装请通过飞牛桌面入口完成管理员注册，再开放外部端口；已在同一浏览器飞牛入口登录旧版原账号的实例，可在 **配置 → 访问鉴权** 点击「迁移旧账号到入口登录」。忘记密码时，在内核运行状态下以飞牛管理员打开管理台 → **配置 → 访问鉴权 → 重置 QwenPaw 管理员密码**，输入两遍新密码保存即可用原用户名登录（要求已安装并启动匹配适配的 `2.3.0.post1` 内核；若内核由管理服务重启后接管，请先在「概览」重启一次服务再重置密码）。
- **外观、风格与语言设置**：顶栏的主题按钮在「白天」与「夜晚」之间切换，语言按钮在「中文」与「EN」之间切换。要恢复「跟随系统」或切换「默认 / Miuix」界面风格，请在 **配置** 分区中选择。
- **协议边界**：上游 WebSocket 当前不由此外壳代理，相关请求返回 `501`；主 Console 的 HTTP、鉴权与 SSE 流程均经 Gateway 或独立反代转发。

## 安装前离线备份

在控制台 **概览 → 部署版本** 勾选「安装前备份已有数据」后再确认安装、升级或重装时，外壳会在确认内核停机后，使用系统 GNU `tar` 备份并校验共享目录下的 `.qwenpaw` 及已有 `.qwenpaw.secret`（首次空目录跳过，备份或校验失败将中止本次安装）。该备份仅包含业务数据，不含运行环境、外壳配置、外部授权目录或上游 ZIP 备份库。

1. 备份文件位于应用私有 `var` 目录（通常为 `/var/apps/qwenpaw/var/preinstall-data.tar`），可能含敏感凭证且不提供浏览器下载。请由 NAS 管理员及时复制到应用目录外的安全位置；重复勾选不会覆盖旧归档，需先移走原文件才能生成新备份（`.partial` 为未完成文件，不可用于恢复）。
2. 如需离线恢复，请勿覆盖运行中的工作区或导入上游 ZIP 备份页。先停用应用，用 `tar -tf preinstall-data.tar` 核对清单，再解压至**新的空私有目录**（如 `tar --acls --xattrs -xpf preinstall-data.tar -C <恢复目录>`）。
3. 核对配置、工作区与凭证后，先另存当前数据目录，再按原应用账户属主、权限与 ACL 放回原共享位置。若控制台提示存在待恢复事务，请保留现场并查看日志，不要手动删除事务文件强行启动。

## 升级、回退与卸载

- **外壳与内核双轨**：外壳升级默认保留用户已安装的内核版本（历史 `1.3.3` 系列仅对健康 `2.3.0` 执行过一次 `2.3.0.post1` 事务迁移）。运行环境缺损时按版本钉恢复。
- **回退旧外壳**：fnOS 不支持直接覆盖安装更低版本 FPK。如需回退，请确认无未决事务及数据格式冲突后，执行「保留数据卸载 → 安装目标旧包 → 核验」。
- **保留数据卸载**：保留用户配置、聊天记忆与管理员认证，仅清理运行环境；重装时按版本钉恢复环境。控制台中的「仅卸载内核」同样保留用户数据。
- **彻底删除**：删除运行环境与应用自有数据目录，不删除另行授权的外部目录；操作不可逆，无事前外部备份无法恢复已删除的应用数据。

## 常见问题

### 控制台提示「内核未安装」或无法打开 Web 对话

首次安装外壳后尚未包含 QwenPaw 内核，请在 **概览 → 部署版本** 点击「检查更新」，选择目标版本（标记「随包适配补丁」代表与本包补丁匹配）并安装，完成后服务会自动启动。若已安装仍无法进入，请确认概览状态为「运行中」，再到 **日志** 查看启动输出、端口冲突或网关报错。

### 安装、升级失败或提示找不到版本

检查 NAS 网络与 DNS，确认当前下载源可访问且包含所选版本；镜像返回 403、连接超时或未同步目标版本时，在 **概览 → 部署版本** 切换其他 PyPI 镜像源后重新点击「检查更新」。安装采用独立暂存环境，失败时会自动尝试恢复原运行环境；若已有安装任务正在运行，请点击顶栏「查看安装任务」查看进度，不要重复提交。

### 忘记 QwenPaw 管理员密码或外部设备无法登录

独立 Web 反代使用 QwenPaw 原生账号（与飞牛 NAS 账号独立）；飞牛桌面入口按迁移状态使用原账号或飞牛管理员身份。开放局域网独立反代前，请先通过飞牛桌面入口完成管理员注册。忘记密码时，确保带适配的内核处于「运行中」，用飞牛管理员打开 **配置 → 访问鉴权 → 重置 QwenPaw 管理员密码**，设置新密码后即可用原用户名登录（若提示内核由管理服务重启后接管，请先在「概览」重启一次服务再重置）。

### 如何授权 NAS 目录读写或备份恢复数据

在 **授权与备份** 分区点击「选择飞牛目录」，完成飞牛文件授权后即可绑定到 QwenPaw 工作区；点击「移除绑定」仅解除工作区关联，不会删除目录或文件。日常备份可点击「打开备份管理」使用上游备份页面；安装前在 **概览 → 部署版本** 勾选「安装前备份已有数据」则会在停机后将 `.qwenpaw` 与 `.qwenpaw.secret` 归档至应用私有 `var/preinstall-data.tar`（详见上文「安装前离线备份」）。

### 页面提示安全凭证已刷新（CSRF）、来源校验失败或「需要恢复」

若提示页面安全凭证已刷新或 CSRF/来源校验失败，请重新执行操作或强制刷新控制台，并确认正通过飞牛 Gateway 地址访问管理台。若概览提示「需要恢复」，说明上一次安装或配置事务尚未完成恢复，请勿手动删除事务文件或运行目录，先在 **日志** 导出运行日志并提交 Issue。

### 手机端上传 `.fpk` 失败

优先使用电脑浏览器上传，或先将 `.fpk` 放入 NAS 共享目录，再在应用中心选择「从 NAS 添加」。

### 使用 Ollama 时 API Key 如何填写

在 QwenPaw 中填写任意非空字符串（例如 `ollama`），不要复用其他真实服务的密钥。

## 开发与验证

生产管理核心使用 Rust（`supervisor/`），控制台前端使用 Vue 3 + TypeScript（`web/src/`，Vite 构建时预编译为静态单页），fnOS `cmd/*` 仅作生命周期薄入口转发；QwenPaw 本体不在本仓库内。

```bash
# 前端检查与构建
npm ci --prefix web
npm run typecheck --prefix web
npm test --prefix web
npm run build --prefix web

# Rust 检查与测试
cargo test --locked --manifest-path supervisor/Cargo.toml
cargo clippy --locked --manifest-path supervisor/Cargo.toml --all-targets -- -D warnings

# 一致性与综合门禁
python3 scripts/sync-version.py --check
python3 scripts/gen-audit.py --check
bash scripts/preflight.sh
STRICT_CI=1 bash scripts/lint.sh
bash build.sh
```

完整测试均在隔离临时目录中运行，不会接触真实 NAS 服务或用户数据。`build.sh` 负责 musl 静态 release 构建、前端打包、FPK 生成与内容审计（构建机需安装 `musl-tools`，Rust 工具链由 `rust-toolchain.toml` 固定）。

常见问题处理

无法打开 Web 对话

先在概览确认内核已安装且正在运行，再刷新状态。仍无法打开时，到运行日志检查端口、健康检查和网关错误。

安装或更新失败

检查 NAS 网络与 DNS，在版本管理中切换下载源后重试。已有任务时先打开任务详情，不要重复提交安装。

忘记 QwenPaw 管理员密码

在“配置”中使用“重置 QwenPaw 管理员密码”，然后回到对话端重新设置。该操作不修改飞牛账号、配置或记忆。

升级后出现权限或运行异常

保留日志和用户数据，不要手工删除 venv 或共享目录。记录错误时间与提示，到项目 Issues 附上日志反馈。
